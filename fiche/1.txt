FICHE 1 – STRUCTURE DE BASE ET VÉRIFICATIONS INITIALES
Objectif de la fiche
Créer la structure de base du script et implémenter toutes les vérifications préliminaires. À la fin de cette fiche, le script doit être capable de :

Demander le nom de base à l'utilisateur

Vérifier que FFmpeg et FFprobe sont installés

Vérifier que les dossiers video/ et audio/ existent

Vérifier que chaque dossier contient au moins un fichier vidéo valide

Vérifier que les deux dossiers contiennent le même nombre de fichiers

S'arrêter immédiatement si une vérification échoue, avec un message clair

Aucun traitement vidéo pour l'instant – juste les validations.

Détails techniques à implémenter
1. Saisie du nom de base
Utiliser input() pour demander le nom de base

Si l'utilisateur entre une chaîne vide, lui redemander ou utiliser un nom par défaut ("output")

2. Vérification de FFmpeg et FFprobe
Utiliser subprocess.run() pour exécuter :

bash
ffmpeg -version
ffprobe -version
Si la commande échoue (returncode != 0) → erreur et arrêt

Capturer l'exception si la commande n'existe pas

3. Vérification des dossiers
Utiliser os.path.isdir() pour vérifier que video/ et audio/ existent

Si un dossier manque → message et arrêt

4. Vérification du contenu des dossiers
Utiliser os.listdir() pour lister le contenu

Filtrer uniquement les fichiers vidéo (extensions autorisées)

La liste des extensions autorisées est définie dans le script

Extensions autorisées :

python
EXTENSIONS_VIDEO = {'.mp4', '.mkv', '.avi', '.mov', '.webm'}
Si un dossier ne contient aucun fichier vidéo → erreur et arrêt

Si un dossier contient des fichiers non-vidéo → on ignore (on ne filtre QUE les vidéos)

5. Vérification du nombre de fichiers
Compter les fichiers vidéo dans video/ (liste triée)

Compter les fichiers vidéo dans audio/ (liste triée)

Si les nombres sont différents → erreur et arrêt

Important : Les fichiers doivent être triés par ordre alphabétique pour l'appariement futur. Utilise sorted().
